Para la Entrevista Técnica System Design & Algoritmos

Puntos clave que este proyecto demuestra ante los reclutadores:

  • ✓ Mapeo de Rutas y Redirección 302: Se utiliza el código HTTP 302 (Found) en lugar de 301 (Permanent) para evitar que los navegadores guarden el destino en caché y garantizar la auditoría de cada clic en tiempo real.
  • ✓ Algoritmo de 6 Caracteres Base62: Con un alfabeto alfanumérico [0-9a-zA-Z] y longitud 6, el espacio disponible es de 62⁶ (~56.8 mil millones) de combinaciones únicas.
  • ✓ Manejo Eficiente de Colisiones: Bucle de reintentos con SecureRandom y restricción única indexada en base de datos para garantizar consistencia y rendimiento O(1) en consultas.
  • ✓ Arquitectura Limpia en Capas: Separación estricta entre Entidad, Repositorio (JPA), Capa de Servicio (Transaccional) y Controladores duales (Web MVC + REST API).
